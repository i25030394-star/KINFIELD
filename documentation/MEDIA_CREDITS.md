# Illustration and media notes

## Original artwork

The Kinfield sprout mark and four garden illustrations (`window-garden.svg`, `herb-club.svg`, `seed-kit.svg`, and `balcony-plan.svg`) were drawn specifically for this project as original vector artwork. They do not use stock photography.

## Video

The embedded flower MP4 is the publicly hosted CC0 sample video used in MDN Web Docs media examples:

- [Flower video sample](https://interactive-examples.mdn.mozilla.net/media/cc0-videos/flower.mp4)
- [MDN media examples](https://developer.mozilla.org/en-US/docs/Web/HTML/Element/video)

The clip is streamed from MDN, so playback requires an internet connection. It is an illustrative flower clip and does not depict the fictional Kinfield business.
