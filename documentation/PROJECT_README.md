# Kinfield - Garden Studio

An English single-page website concept for the ICT2215 Assessment 2, Set A brief.

Open `index.html` in a modern browser after extracting the full folder. The design uses plain HTML and CSS, local original SVG art and one externally hosted CC0 MP4. No installation, backend or account is needed. The film needs an internet connection.

## Brief coverage

| Brief item | Website implementation |
| --- | --- |
| New project and target audience | Fictional small-space gardening studio for city beginners |
| One landing page | Home, studio, services, video and contact sections |
| HTML and CSS | `index.html` and `styles.css` |
| Working navigation | Internal links to page sections |
| Display-only contact form | Required name/email/message fields and native validation |
| At least 3 images | Four original local SVG illustrations |
| At least 1 video | Embedded flower sample MP4 with native controls |
| At least 3 icons or graphics | Original brand mark and three inline SVG feature icons |
| Design plan | `documentation/DESIGN_PLAN.md` and homepage wireframe |
| Media information | `documentation/MEDIA_CREDITS.md` |

The form has no backend and does not send or store visitor information. Kinfield and its service details are fictional. The assignment asks for student-authored text; rewrite the supplied page copy in your own words before submitting.
